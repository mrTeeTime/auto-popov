AUTO-POPOV.cz – podklady k nasazení

Struktura:
- index.html
- css/style.css
- js/script.js
- php/send-mail.php
- assets/images
- assets/icons

Důležité:
1. Web je čisté HTML5 + CSS3 + vanilla JavaScript.
2. Fonty Barlow / Barlow Condensed se načítají z Google Fonts.
3. Formulář lokálně validuje povinná pole bez reloadu.
4. Pro skutečné odesílání doplňte v php/send-mail.php hodnotu $recipient.
5. Funkce mail() vyžaduje, aby hosting měl nakonfigurované odesílání pošty. Pokud hosting mail() nepodporuje, nahraďte tuto část SMTP řešením daného hostingu.
6. Header používá skutečný HTML text AUTO-POPOV.cz. Červená linka karoserie je oříznutá z dodaného zdrojového loga POVKO.cz, protože samotný dodaný logo soubor textově neodpovídá mockupu AUTO-POPOV.cz.

Kontaktní údaje a texty jsou podle dodaného dokumentu Text AUTO POPOV FINAL.odt.
